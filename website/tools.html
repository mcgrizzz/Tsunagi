AnkiConnect tools that work with Tsunagi

Each tool's code was read at a commit, and every request it sends is checked against Tsunagi on every change. Switch from AnkiConnect and these keep working, with no change to the tool.

How tools are checked

  • Every AnkiConnect action has tests of its own (see AnkiConnect parity). The tools are extra insurance, in case a tool sends something those tests don't expect.
  • For each tool, its source was read at the commit shown and every request it sends to Anki written down. On every change, Tsunagi's tests check that each of those requests gets the answer AnkiConnect gave before its October 2026 rewrite, including for cards that are new, learning, in review, relearning, suspended, buried or in a filtered deck.
  • The tools' own code isn't run, so what a tool does with Anki's windows, such as opening the Browser, isn't covered.
  • Want a tool added to the checks? Open a pull request with its declaration (how to write one: read its code, list what it sends), or open an issue naming it and we'll add it.
