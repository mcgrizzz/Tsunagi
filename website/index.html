tsunagi, a connection

Connects your apps and tools to Anki

An Anki add-on that answers AnkiConnect's requests, so the tools you use keep working, and adds an API of its own for apps: fewer requests, changes as they happen, and a key and role for each app. This page shows how, step by step.

    3. Changes, as they happen

    Change this toy note in Anki's Browser, as you would, or through the API, as an app would. You can type in it too. An app on the Tsunagi API listens to its event stream and is told about each change. A tool on AnkiConnect has no events, so it keeps asking: asbplayer asks every 10 s for every card edited or reviewed today, then works out what's new.
