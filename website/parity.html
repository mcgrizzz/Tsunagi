How this is checked

  • The list of actions comes from AnkiConnect's code, not its README, and the test suite fails if Tsunagi answers an action this page doesn't list, or lists one it doesn't answer.
  • Every action has tests, except getProfiles and loadProfile, which need Anki's real profile manager and are checked by hand. Actions that drive Anki's windows are tested with stand-ins for them, or in a real Anki running offscreen.
  • Answers and errors are compared with AnkiConnect's for the requests the tests cover, and each tested tool's requests are replayed against Tsunagi.
  • Permissions come from each action's registration in Tsunagi; the Tsunagi API routes are checked against the API description when this site is built.
  • Everything here is from the parity page in the docs, which also lists the differences you might notice.
